🔗 Conectar con Google Sheets
Vincula tu Google Sheet para que el sistema jale los datos automáticamente al abrir.
📋 Pasos:
1. Abre tu Google Sheet → Extensiones → Apps Script
2. Pega el script y despliega como Web App (acceso: cualquiera)
3. Copia la URL generada y pégala aquí
// Apps Script — pega esto en tu Google Sheet function doPost(e) { const data = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName(data.hoja) || ss.insertSheet(data.hoja); if (sheet.getLastRow() === 0) sheet.appendRow(data.headers); sheet.appendRow(data.row); return ContentService.createTextOutput(JSON.stringify({ok:true})) .setMimeType(ContentService.MimeType.JSON); } function doGet(e) { const ss = SpreadsheetApp.getActiveSpreadsheet(); const hoja = e.parameter.hoja || 'CONDUCTORES'; const sheet = ss.getSheetByName(hoja); const data = sheet ? sheet.getDataRange().getValues() : []; return ContentService.createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); }
